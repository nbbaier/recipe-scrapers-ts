- **`getMinutes` blind hyphen split** (`src/utils/time.ts:63-68`, mangles
  `"1-1/2 hours"`-style inputs): deferred. The behavior mirrors the upstream
  Python port, the practical output for the known failing shape is identical
  after the split anyway (both routes parse to the fractional value), and
  changing range detection risks parity for no demonstrated fixture. Revisit
  only with a real-world fixture that produces a wrong duration.
- **`bestMatch` unguarded `scores[0]` on empty ingredient list**
  (`src/utils/grouping.ts:91`): analysis shows the empty-list path returns
  early (`groupIngredients` either takes the no-selector early return or throws

  Plan 001 Step 2 documents this with a characterization test; no fix planned.
- **`containsSchemaType` substring matching** (`src/parsers/schema-org.ts:179-181`,
  `@type: "RecipeReview"` would match a search for `"Recipe"`): LOW confidence,
  no triggering fixture found; not planned. Re-raise if a mis-parsed site
  appears.
- **`toJson` swallowing is by design (Python parity)**: partially true — the
  skip-on-missing-data contract is kept; only observability is added (plan 005).
